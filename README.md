# NOVA - AI Fashion Chatbot 👗✨

## Overview

NOVA is an AI-powered fashion chatbot that provides personalized styling suggestions and outfit recommendations through an interactive conversational interface.

The system uses Artificial Intelligence to understand user preferences and generate fashion advice, helping users make better outfit choices and reducing uncertainty during online shopping.

---

## Features

✨ AI-powered fashion recommendations  
💬 Interactive chatbot conversation  
👗 Personalized outfit suggestions  
🧠 AI-generated styling advice  
📜 Chat history management  
🌐 Responsive web interface  

---

## Problem Statement

Online shoppers often struggle with choosing outfits that match their style, occasion, and preferences.

NOVA addresses this problem by providing an AI-based virtual fashion assistant that delivers personalized styling recommendations in real time.

---

## Project Workflow

1. User enters fashion-related queries through the chatbot interface.
2. The request is processed by the FastAPI backend.
3. User input is sent to the Hugging Face API.
4. AI generates personalized fashion advice.
5. Response is displayed through the chatbot interface.
